# Forest — сборки и обновления

Здесь нет исходного кода игры — только раздел **Releases**:

* `v<версия>` — готовые сборки Forest для Windows, macOS, Linux и Android
  и манифест `version.json` с размером и SHA-256 каждого файла;
* `updates` — канал автообновления: актуальный `version.json`, который игра
  читает при запуске по адресу
  `https://github.com/Gosha8046/Forest-game-Relis/releases/download/updates/version.json`.

Релизы публикует сборочный конвейер игры автоматически; вручную здесь ничего
менять не нужно.
